# 機不可失：行動電話發展史

期末報告的線上互動博物館。沒有建置步驟，純 HTML / CSS / JavaScript。

## 內容

- **心理測驗**：入場前先做 4 題測驗，結果會對應一支代表手機，可以直接跳到時間軸或 3D 展廳看它。
- **平面時間軸（主要動線）**：點年代或左右滑動切換，每支手機是一張卡片，點一下會翻面顯示介紹。
- **3D 展廳**：每支手機放在展台上，排成一條時間走廊。可以拖曳旋轉手機，用左右鍵、箭頭按鈕或點其他展台移動。
- **沉浸體驗**：在 3D 展廳點有橘色光圈的手機（或時間軸上的「▶ 沉浸體驗」按鈕），會進入全 3D 的情境重現。演出段落和自由參觀段落交替，自由參觀時把畫面中央的準星對準發光的圓點，就會跳出解說。視角可以拖曳，手機上也可以開「體感」直接轉動手機。目前做好的是 DynaTAC 8000X（1984 年的街頭）。
- **重要人物、延伸議題、資料來源**

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面架構 |
| `css/style.css` | 樣式 |
| `js/data.js` | **所有展覽內容**（年代、手機、人物、議題、測驗）。改文字只要改這裡，2D 和 3D 會一起更新 |
| `js/app.js` | 測驗、時間軸、模式切換 |
| `js/hall3d.js` | 3D 展廳（Three.js）。手機模型是用程式畫的簡化模型，不需要另外下載 3D 檔 |
| `js/immersive.js` | 沉浸體驗的播放器：視角、陀螺儀、字幕、發光點解說 |
| `js/scene-kit.js` | 沉浸場景共用的小人、建築、汽車等零件 |
| `js/scenes/*.js` | 每個沉浸場景的布景和人物動作 |
| `images/` | 手機照片放這裡 |

## 放照片

把照片放進 `images/`，檔名要跟 `js/data.js` 裡每支手機的 `img` 一樣，例如 `images/nokia-3310.jpg`。
還沒放照片的卡片會顯示提示，告訴你該用哪個檔名。記得在資料來源註明照片出處。

## 改沉浸體驗的劇本

字幕、解說文字都在 `js/data.js` 的 `scenes`，改文字不用碰程式：

- `type: 'play'` 是演出段落。`captions` 裡的 `at` 是第幾秒出現那句字幕。
- `type: 'explore'` 是自由參觀段落。`hotspots` 列出這段可以看的發光點，解說內容寫在下面的 `hotspots`。

想新增其他手機的場景，先把劇本寫好（地點、有哪些人、每一段發生什麼、字幕、解說），人物動作和布景要另外寫在 `js/scenes/` 裡。

**陀螺儀（體感）**：只有在 https 網址（例如 GitHub Pages）的手機瀏覽器上才能用，iPhone 會先跳出授權視窗。在 Claude 的預覽網址、電腦上，或沒有授權時，會自動改用手指拖曳。

## 本機預覽

3D 展廳用到 JavaScript 模組，直接雙擊 `index.html` 開會載入失敗，要用網頁伺服器開：

```bash
python3 -m http.server 8000
# 然後打開 http://localhost:8000
```

VS Code 也可以用 Live Server 擴充功能。

## 發布到網路（GitHub Pages）

到 GitHub repo 的 **Settings → Pages**，Source 選 `Deploy from a branch`，選分支和 `/ (root)`，存檔後等一兩分鐘就會有網址。
